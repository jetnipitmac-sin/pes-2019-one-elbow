# One Elbow · PES 2019 — Signature Dashboard

**เปิดดูออนไลน์:** https://jetnipitmac-sin.github.io/pes-2019-one-elbow/

เว็บเล่าเรื่องเคสไฟไหม้หน่วย HF alkylation โรงกลั่น PES ฟิลาเดลเฟีย (21 มิ.ย. 2019) แบบ scroll-driven
มีโมเดล 3 มิติของข้องอที่แตกเป็นตัวเดินเรื่อง เลื่อนลงแล้วผนังท่อบางลงทีละปีจาก 1973 ถึง 2019 จนแตก
ตัวเลขทุกตัวมาจากไฟล์ชุดเดียวกับรายงานใน `01_Report` (CSB, รายงานเมืองฟิลาเดลเฟีย, EIA และ `calc.py`)

โฟลเดอร์นี้แยกจาก `06_Dashboard` (เวอร์ชันการ์ด + ฉากแอนิเมชัน) ไม่ได้แก้ของเดิม

> repo นี้เก็บเฉพาะตัวเว็บ (โฟลเดอร์ `07_Signature_Dashboard` ของงานวิเคราะห์เคส) ข้อมูลที่ใช้แสดงผลอยู่ใน `src/data/pes.json` แล้ว
> clone มาแล้ว `npm install` กับ `npm run dev` ได้เลย ไม่ต้องมีไฟล์อื่น

## เปิดใช้งาน

ต้องมี Node 18 ขึ้นไป (เครื่องนี้ใช้ `/opt/homebrew/opt/node@20/bin`)

```bash
npm install        # ครั้งแรกครั้งเดียว
npm run dev        # เปิด http://localhost:5250
```

ทุกครั้งที่ push ขึ้น `main` GitHub Actions (`.github/workflows/deploy.yml`) จะ build แล้วอัปเดตเว็บออนไลน์ให้เอง

ทำไฟล์สำหรับเผยแพร่เอง (`dist/` ใช้ path แบบ relative วางบนเว็บเซิร์ฟเวอร์ไหนก็ได้):

```bash
npm run build
npm run preview    # ดูไฟล์ที่ build แล้วที่ http://localhost:5251
```

ทางลัดตอนนำเสนอ

- `?at=<บท>&p=<0–1>` กระโดดไปยังบทและตำแหน่งในบทนั้นทันที เช่น `?at=anatomy&p=0.5` (ปี ~1994), `?at=rupture&p=0.7` (ไอติดไฟ)
  ชื่อบท: `hero` `manifesto` `anatomy` `rupture` `night` `toll` `forensics` `barriers` `reach` `cost` `fixes` `epilogue`
- `?still` ข้ามหน้าโหลดและปิดการเลื่อนแบบนุ่ม (ใช้ตอนตรวจหน้า หรือเครื่องที่ช้า)
- ปุ่ม Menu มุมขวาบน กระโดดไปบทไหนก็ได้ · Esc ปิดเมนู

## ข้อมูลมาจากไหน

`tools/build_data.py` (สคริปต์เดียวกับ `06_Dashboard`) อ่าน `05_Data_and_Code/results.json` และ CSV ทั้งสามไฟล์ แล้วเขียน `src/data/pes.json`
(`npm run data` ต้องรันในโฟลเดอร์เคสเต็มที่มี `05_Data_and_Code` อยู่ข้างๆ ใน repo นี้อย่างเดียวรันไม่ได้ แต่ไม่จำเป็น เพราะมี `pes.json` ให้แล้ว)
สคริปต์เช็กว่าค่าเฉลี่ย ก.ค.–ธ.ค. จาก CSV ตรงกับ `results.json` ถ้าไม่ตรงจะหยุด ถ้าแก้ตัวเลขในรายงาน: `python3 calc.py` → `npm run data`

ข้อจำกัดที่ควรรู้ก่อนนำเสนอ

- โมเดล 3 มิติวาดตามขนาดจริงของข้องอ NPS 8 Sch 40 แบบ long radius แต่ **ผนังวาดหนากว่าจริง 3 เท่า** เพื่อให้มองเห็น สัดส่วนความหนาระหว่างข้องอกับท่อข้างๆ ตามจริง
- ผนังบางลงด้วยอัตราเฉลี่ยคงที่ (0.322 → 0.011 นิ้ว ใน 46 ปี) ตำแหน่งจุดที่บางที่สุดบนโมเดลเป็นภาพประกอบ
- แผนผังจุดวัดความหนา (Exhibit C) จำนวนจุดตามรายงาน แต่ตำแหน่งเป็นภาพจำลอง
- ความกว้างของลำแสงในบท Layers และทิศลมในบท Reach เป็นภาพประกอบเชิงคุณภาพ ไม่ใช่ค่าคำนวณ

## โครงสร้าง

```
07_Signature_Dashboard/
├── tools/build_data.py        CSV + results.json → src/data/pes.json
├── src/
│   ├── App.jsx                ประกอบทุกบท + สลับธีมมืด/กระดาษ + เปิด/ปิด WebGL ตามบท
│   ├── gl/
│   │   ├── elbowGeometry.js    สร้างข้องอ + ท่อสองข้างแบบผ่าครึ่ง, setYear() ขยับผนังด้านในตามปี
│   │   ├── materials.js        shader: แผนที่ความร้อนบนรอยผ่า, ไอพุ่ง/ลูกไฟ, ฝุ่นประกายไฟ, ฉากหลัง
│   │   └── Stage.jsx           Canvas + "director" ที่อ่านค่าการเลื่อนแล้ววางกล้อง/โมเดล/แสงทุกเฟรม
│   ├── sections/              Story (hero/เรื่องย่อ/anatomy/rupture), Night, Toll, Forensics,
│   │                          Barriers, Reach, Cost, Fixes, Epilogue
│   ├── components/            chrome.jsx (preloader, cursor, nav, menu), ui.jsx (odometer, reveal, marquee, tooltip, ที่มา)
│   ├── lib/                   scroll.js (Lenis + ScrollTrigger + stage), data.js, sources.js
│   └── styles/                base.css (token สีทั้งหมด), ui.css, sections.css
└── package.json
```

สีทั้งหมดเป็น token ที่ต้น `src/styles/base.css` สีของกราฟ (ส้ม ember กับฟ้า steel) ผ่านการตรวจตาบอดสีทั้งบนพื้นกระดาษและพื้นมืด

## ถ้าเครื่องช้า

หน้าเว็บปรับความละเอียดของภาพ 3 มิติลงเองเมื่อเฟรมเรตตก (เริ่มที่ 1.25× ลดได้ถึง 0.75×) และจำกัดไว้ที่ ~60 fps แม้จอ 120 Hz
ภาพ 3 มิติทำงานเฉพาะช่วงบทแรกกับบทสุดท้าย บทกลางเป็น HTML/SVG ล้วน ถ้ายังกระตุกให้เปิดด้วย `?still`
ถ้า GPU ทำ WebGL context หลุด (หน่วยความจำไม่พอ) ภาพ 3 มิติจะซ่อนตัว เนื้อหาอื่นยังอ่านได้ปกติ
